02 / Alternatives and decision

Two approaches.
One choice.

Approach A — Recruiter-first

A conventional landing page would prioritize education, skills, experience, and résumé links. It is fast to scan, but could make code and project evidence secondary.

Approach B — Technical project-first

A technical homepage would foreground selected programming projects, code links, contributions, and documented results. This provides stronger evidence, but can feel overwhelming if too many projects are featured.

Decision: Approach B, with selective highlighting. Only the strongest relevant projects should be featured. Other required projects remain accessible in a secondary area. Clear navigation and professional links preserve the scanability of Approach A.

Assumption: This approach will help the intended reader inspect my work. Its usability has not yet been tested with an external reviewer.
